# Note Toolbar Features

Answer questions about what the Obsidian Note Toolbar plugin can and cannot do, from the reference included with this skill.

Read `references/features-reference.md` before answering. Use it as the authoritative reference for features, positions, item types, display rules, styles, the Gallery, callouts, scripting and integrations, built-in commands, platform differences, and limitations. Do not fetch the wiki version instead: the included reference is the version matched to this checkout.

## Answering guidance

The reference is a snapshot of Note Toolbar **v1.35.x** (October 2026). Treat it as authoritative for that version.

- Distinguish shipped vs in-development vs planned, and give the version when a feature has one. Never present in-development or planned items as available.
- If a capability is not described in the reference, say it isn't covered rather than guessing. Do not invent item types, positions, styles, or settings.
- Route the user to the sibling skill for the task: scripts → note-toolbar-api; creating/changing toolbars → note-toolbar-cli or note-toolbar-callouts; ready-made items → note-toolbar-gallery; dynamic labels/links → note-toolbar-variables.
