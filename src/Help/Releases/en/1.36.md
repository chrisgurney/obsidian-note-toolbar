# What's new in Note Toolbar v1.36?

If you find this plugin useful, [consider donating ↗](https://buymeacoffee.com/cheznine). Thank you! ❤️

_Make sure you've updated to the latest version to get all of these changes._

## Improvements 🚀

### Scripts: Error reporting improvements

Errors reported on script execution now provide:
- more information about where the error originated (e.g., item, script file, etc.)
- a link to edit the toolbar item from the notification

On mobile, error messages (and debug messages, if enabled) are displayed in a _Note Toolbar errors_ sidebar. Previously, you would have needed a plugin like [vConsole ↗](https://community.obsidian.md/plugins/vconsole) to capture these.

_Try it out, and let me know how error reporting can be improved!_

### _Reveal_ + _Open_ file links in settings

For file items, URI items, and for script items that use files, links have been added underneath fields that conveniently:
- _Reveal_ the file in Obsidian's file explorer (if it's enabled).
- _Open_ the file using Obsidian's file-opening behavior. Note that files that Obsidian doesn't support may be opened using an external application.

### Other improvements

- `1.36.12` Localization: Strings for the CLI and Gallery have been moved to i18next-compatible JSON format files, under the `src/I18n/cli` and `src/I18n/gallery` folders, respectively.
- `1.36.12` Styles (settings): Clicking in a chip puts focus on the delete button, which then lets you use `backspace` to delete it; keyboard focus then moves to the next chip on delete.
- `1.36.10` Toolbar items now have fallback tooltips (e.g., name of the command, or URI) if a tooltip is not provided.
- `1.36.10` Toolbar settings: Use the keyboard to move (`cmd/ctrl + arrows`), duplicate (`cmd/ctrl + d`) and delete (`backspace`) items in the list more easily now; focus is now also kept in the item list.
- `1.36.10` Mobile error sidebar: Added an _export_ button, so that messages can be copied when diagnosing and submitting issues with Note Toolbar.
- `1.36.10` [Agent Skills](https://github.com/chrisgurney/obsidian-note-toolbar/tree/master/skills): added `note-toolbar-features`, and reference files (so agents don't have to fetch remote URLs).
- If any errors occur while migrating settings, Note Toolbar's settings are preserved, and an option to export them is provided (so that you can attach them to an issue on GitHub for analysis).
- In case you missed it in `1.35`, the `tab file item` style has been renamed to the `active file` style. See [Styling toolbars](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Styling-toolbars#how-styles-are-applied) for more details.
- Removed a number of toolbar re-renders that are unnecessary on settings changes.
- [Templater](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Templater): When setting up an to _Insert_ or _Create new notes_ from templates, the file option now shows _all_ files, not just those in Templater's _Template folder location_.
- [JS Engine](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/JS-Engine): Uses full paths to resolve files.

## API

### ntb.exportSettings()

Back up Note Toolbar's settings from a script. This function copies `data.json`, exactly as stored, to a timestamped file in the "Note Toolbar Backups" folder in your vault by default. [Learn more.](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Note-Toolbar-API#exportsettings)

```js
const backupPath = await ntb.exportSettings();
```

```js
// or give it a name (a folder path in your vault also works)
await ntb.exportSettings("my-backup");
```

### ntb.sidebar(): `append`, `class`, and `navigation` options

- Set `append` to a separator (e.g., `'\n---\n'`) to append text content using a provided separator string, instead of replacing it. Only applies when a sidebar is being reused.
- Use `class` to add one or more CSS classes to the sidebar, separated by spaces.
- Set `navigation: ['clear', 'close', 'export']` to display a small toolbar in the sidebar with these available buttons:
  - `'clear'`: to clear out the content area of the sidebar. Use when opening text, when using the `append` option. 
  - `'close'`: to more conveniently close the sidedbar.
  - `'export'`: export the sidebar's text contents to a file, prompting for a filename. 

All the options [are documented here](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Note-Toolbar-API#sidebar).

_Try it out, and let me know what you're using ntb.sidebar for!_

### ntb.prompt() and ntb.suggester(): `title` option

Both now accept a `title` option as a synonym for `label` (the text shown above the input field).

```js
const name = await ntb.prompt({ title: "Note Toolbar backup filename" });
```
