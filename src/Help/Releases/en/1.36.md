# What's new in Note Toolbar v1.36?

If you find this plugin useful, [consider donating ↗](https://buymeacoffee.com/cheznine). Thank you! ❤️

_Make sure you've updated to the latest version to get all of these changes._

## Improvements 🚀

### Script error reporting improvements

Errors reported on script execution now provide:
- more information about where the error originated (item, script file, etc.)
- a link to edit the toolbar item from the notification
- in settings, links under the script file conviently: reveal the file, or open it (if the file type is supported)

On mobile, error messages (and debug messages if enabled) are displayed in a _Note Toolbar errors_ sidebar. Previously, you would have needed a plugin like [vConsole](https://community.obsidian.md/plugins/vconsole).

_I'd love to know your feedback on this feature. Let me know!_

### Other improvements

- [Templater](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Templater): When setting up an to _Insert_ or _Create new notes_ from templates, the file option now shows _all_ files, not just those in Templater's _Template folder location_.
- [JS Engine](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/JS-Engine): Uses full paths to resolve files.

## API

### ntb.sidebar options: `active`, `id`, `navigation`

- Set `active: false` so that when any content is sent to that sidebar, the sidebar view will not be displayed automatically. The default is `true`.
- Use an `id` to give the sidebar a unique identifier, so content always goes to that particular sidebar. For example, when using the `append` option.
- Set `navigation: true` to display a small toolbar in the sidebar with these buttons:
  - _Clear_, to clear out the content area of the sidebar. Use when opening text, when using the `append` option. 
  - _Close_, to more conveniently close the sidedbar.

_I'd love to know what you're using the sidebar for. Let me know!_
