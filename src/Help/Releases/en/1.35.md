# What's new in Note Toolbar v1.35?

> [!note]
> It is strongly encouraged to make a backup of your Note Toolbar's `data.json` file before proceeding, and/or test within a separate vault. Your mappings settings will be migrated to the new rules configuration in this version.

_Make sure you've updated to the latest version to get all of these changes._

## New Features 🎉

### Rules

Toolbars can now be mapped to a lot more than just folders. Create a rule for each toolbar, including checking parts of file, folder, or tag names:

- editor mode `is | is not` _editing_ or _reading_
- file name `contains | does not contain | starts with | ends with | is | is not`
- file type `is | is not` any file type supported by Note Toolbar, including manually entered types 
- folder path `contains | does not contain | starts with | ends with | is | is not`
- platform `is | is not` _desktop_, _mobile_, _phone_, or _tablet_
- tags `contains | does not contain | is empty | is not empty`

This replaces folder mappings. Your folder mappings will be converted into Rules.

Open the Rules window from settings, or with a command: `Note Toolbar: Open rules`.

- If you have a file open, the active rule is highlighted.
- Settings for the `notetoolbar` property, and Default toolbar have been moved here.

**CLI: Rules command**

The `note-toolbar:rules` command lists all rules (including property and default toolbar), and flags the active rule if a file is currently open.

## API

### ntb.getTags()

Lists all tags used in the vault, in alphabetical order.

```ts
const tags = ntb.getTags();
const selected = await ntb.suggester(tags);
new Notice(selected);
```
