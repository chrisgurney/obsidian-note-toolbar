## New Features 🎉

### Rules

Toolbars can now be mapped to a lot more than just folders. Open the Rules window from settings, by right-clicking a toolbar (long-pressing on mobile), or with a command: `Note Toolbar: Open display rules`.

<img src="https://raw.githubusercontent.com/chrisgurney/obsidian-note-toolbar/master/docs/images/rules.png" width="700"/>

Create one or more conditions for each toolbar, including checking parts of file, folder, or tag names:

| Compare...   | using...          | ...with these options/notes |
|--------------|-------------------|-----------------------------|
| editor mode | is • is not | ...`editing` or `reading` |
| file name | contains • does not contain • starts with • ends with • is • is not | |
| file type | is • is not | ...any of the [[file types]] supported by Note Toolbar, including manually entered types (e.g., `excalidraw`) |
| folder path | contains • does not contain • starts with • ends with • is • is not | Use a _folder path_ of `/` for files in the root folder, and `*` for _all_ files. |
| platform | is • is not | ...`desktop`, `mobile`, `phone`, or `tablet` |
| tags | contains • does not contain • is empty • is not empty | |
| _any property_ | exists • does not exist • is empty • is not empty • contains • does not contain | For checkbox properties, use _contains_ `true` or `false` |

**Notes:**

- Rules replaces folder mappings (your folder mappings will be converted into Rules on plugin update).
- Settings for the `notetoolbar` property, and Default toolbar have been moved to the new Rules window.
- If you open the Rules window while you have a file open, the actively applied rule is highlighted.
- Create a rule for _No toolbar_ if you don't want to show a toolbar under a provided set of conditions.
- If any [File types](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/File-types) you want to display toolbars for are not enabled, the Rules window will show an error.

For more details, see [the user guide](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Defining-where-to-show-toolbars).

_Thank you to @AE-SAY-WAY @Azurewren @FelipeRearden @grosserfrank @laktiv @Moyf @notDavid @tosascott and others, for all the suggestions and use cases that led to this feature!_

**CLI: Rules command updated**

The `note-toolbar:rules` [CLI command](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Note-Toolbar-CLI) lists all rules (including property and default toolbar), and flags the active rule if a file is currently open:

```
> note-toolbar:rules

1	(not set or no such toolbar)	toolbar set by property: notetoolbar
2	toolbar:Editor Tools        	IF tags contains #draft OR file name contains "draft"
3	toolbar:Basic *             	IF file type is bases AND folder path is "/"
4	toolbar:No toolbar          	IF file name contains "Ignore"
5	toolbar:Editor Tools        	default (if none of the above rules apply)

* Indicates the active rule in the active file (My Base)
```

## Improvements 🚀

- `1.35.11` [Style Settings](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Style-Settings-plugin-support): Overrides for the floating/text toolbar's orientation and Y offset. [#614](https://github.com/chrisgurney/obsidian-note-toolbar/issues/614) _Thanks @ksdavidc!_
- Gallery: Added `Color highlight`, which toggles color highlighting available in Obsidian 1.14.
- Onboarding message shown when creating your first toolbars provides a _Learn more_ link, and options to easily set the property, open display rules, or set it as the default toolbar.
- Toolbar properties now support using toolbar IDs, which you can copy from **Settings (toolbar list) → Copy developer ID...**
- Reordered the toolbar context menu to group similar actions for clarity.
- Settings: Removed _Show "Edit toolbar" in toolbar menus_ setting, as it only ever applied to floating button menus. Use the right-click/long-press menu to edit a toolbar.
- Combined the _Copy as callout_ and _Share_ modals into one.
- Settings: [Copy as callout settings](https://github.com/chrisgurney/obsidian-note-toolbar/wiki/Creating-callouts-from-toolbars) have been moved to the _Copy as callout_ window. Changing these settings will immediately update the callout text.
- Settings: Text toolbars: Styles that are not applicable are now hidden if opening styles from the context menu.
- Gallery: Now prompts to enable scripting, if any of the items in _Add as toolbar_ requires it.
- Chinese and Ukrainian localization updates by @Moyf and @laktiv

## Fixes 🛠️

- Auto-hidden toolbars no longer re-appear when the view is no longer active / focussed.
- Auto-hidden props-positioned toolbars now disappear on phones, as well. Obsidian's _Appearance → Full sceen_ setting to be enabled.
- Settings: FileSuggester was showing files in the recent list that no longer exist (e.g., were renamed).

## API

### ntb.getTags()

Lists all tags used in the vault, in alphabetical order.

```ts
const tags = ntb.getTags();
const selected = await ntb.suggester(tags);
new Notice(selected);
```
